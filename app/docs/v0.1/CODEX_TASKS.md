# Sandwiches — Codex Tasks

## TASK-000 — Auditoría inicial

### Objetivo
Conocer el estado real antes de implementar nuevas funcionalidades.

### Entregable
Crear AUDIT_REPORT.md con:
- stack
- estructura
- funcionalidades
- datos
- dependencias
- bugs
- deuda técnica
- seguridad
- UX/UI
- contradicciones
- recomendaciones
- primer sprint

### Restricciones
No migraciones destructivas. No reescritura total. No features nuevas salvo que sean necesarias para diagnosticar.
